# K-03 ODbL — 全国版で論点がどう変わったか（2026-10-02）

★**法的な判断をこの文書で代替しない。** 一次情報と、配布物の事実だけを並べる（藤沢版 `docs/Step6_公開準備.md` §7 と同じ立場）。

## 一次情報（2026-10-02 確認）

| 出典 | 要点 |
|---|---|
| ODbL 1.0 §4.4 https://opendatacommons.org/licenses/odbl/1-0/ （日付記載なし） | 公に使う Derivative Database は「この License（または互換ライセンス）の条件のみで」 |
| ODbL 1.0 §4.6 | 公に使うなら、受け手に**派生データベース全体**か**変更内容（作り方）を書いたファイル**を機械可読で提供する（ネット配布なら無償） |
| ODbL 1.0 定義 | 「Publicly」= 自分（または支配下）以外の者が利用できるようにすること |
| OSMF Produced Work ガイドライン https://osmfoundation.org/wiki/Licence/Community_Guidelines/Produced_Work_-_Guideline （最終編集 2016-07-31） | 「公開物が**元データの取り出しを意図**しているなら、それは Produced Work ではなくデータベース」。画像（PNG 等）は典型的な Produced Work。経路グラフ・クライアントへ配るデータファイルについては**明記なし** |

## 全国版の配布物（事実）

| ファイル | 中身 | OSM 由来 |
|---|---|---|
| `data/mesh/*.bin.gz`（4,516枚・578MB） | ノード座標・エッジ・通過時間・道路名・リスクスコア・幅員区分・標高 | 道路網・道路名は OSM。幅員区分・標高は国土地理院 |
| `data/places.json`（26万件） | 町丁目・大字・交差点の**名前と座標の一覧** | OSM（市区町村名は国土数値情報） |
| `data/index.json` | 区画の目録 | — |

★藤沢版（graph.bin 4MB）と比べて:
- 対象が**全国**になり、**認証もパスコードも無い一般公開**（NK-01/04）。「Publicly」に当たることは争いにくい
- `places.json` は**名前と座標の表そのもの**で、元データの取り出しに使える形をしている
- 区画ファイルもすべて URL で直接取れる（ブラウザが取りに行くため、隠しようがない）

## ★判断（2026-10-07・利用者）

- **区画ファイル（`data/mesh/*.bin.gz`）は Derivative Database に当たらない**と判断した（利用者）。
  → 区画ファイルについて Share-Alike（§4.4）・派生DBの提供（§4.6）の対応はしない
- **`places.json`（町丁目・交差点の名前と座標の一覧）も Derivative Database に当たらない**と判断した（利用者・2026-10-07）

## 法務に判断してもらうこと（当初の整理）

1. 区画ファイル・`places.json` は Derivative Database に当たるか
2. 当たる場合の応じ方。考えられる形（★どれを採るかは判断しない）:
   - (a) 配布データを **ODbL で提供する**と明示する（データ自体は既に無償で取れる）。§4.6 は「作り方」の提供でもよい
     （`preprocess/` の手順と設定が当たりうる）
   - (b) 配布データの形を変える（例: 名前の一覧を配らない）
3. ★**国土地理院由来の列（幅員区分・標高）を同じファイルで ODbL にしてよいか。**
   地理院の条件は出典の明示（藤沢版 K-11・全国版 NK-19）。ODbL で再配布したときに出典の要求が保たれるか

## 済んでいること（事実）

- 画面に `© OpenStreetMap contributors (ODbL)` と copyright ページへのリンクを常時表示（`index.html` の出典欄）
- ★**配布データのファイル自体には出典もライセンスも入っていない**（藤沢版の graph.json には attribution があった。全国版の index.json には無い。2026-10-02 確認）
