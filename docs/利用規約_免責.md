# 利用規約・免責・データの出典（全国版）

最終更新: 2026-09-28

## 本アプリについて

本アプリは**実証実験**のアプリです。国土地理院・国土交通省・各地方整備局等が作成・提供する**公式のアプリではありません**。
公式な避難誘導や通行可否の判断を行うものではありません。

## 免責事項（初回起動時に同意を取る。画面は `web/index.html` の `#disclaimer`）

- 示すのは「安全な経路」ではなく、**静的なデータ上、相対的にリスクが低いと推定される経路**です。
- 実際の降雨状況・通行止め・道路状況は反映していません。
- 表示のない区域にも冠水リスクがあります。
- 最終的な通行の判断は、現地の状況に基づいてご自身で行ってください。冠水した道路には絶対に進入しないでください。
- **道路冠水想定箇所**（NK-09・2026-09-28 追加）: 本アプリで表示する道路冠水想定箇所は、各道路管理者が公表しているデータをもとに表示しています。
  実際の道路状況や気象条件により、掲載箇所以外でも冠水が発生する可能性があります。
  通行の際は現地の案内や規制情報に従い、利用者の責任においてご利用ください。
  ★この項目の追加で、既に同意した利用者に同意画面を出し直すことはしない（2026-09-28・利用者判断）。
